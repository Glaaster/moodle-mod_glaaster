Structure du Projet

État : plugin mod_glaaster 5.3.x (fork de mod/lti MOODLE_405_STABLE, services de notes retirés).

Arborescence générale​

moodle-glaaster_activity/
├── mod/glaaster/                # Module principal du plugin
│   ├── amd/                     # Modules AMD JavaScript
│   │   ├── src/                 # Sources JavaScript (pré-minification)
│   │   └── build/               # JavaScript minifié (généré par Grunt)
│   ├── assets/js/               # Scripts hors AMD (iframe-loader.js)
│   ├── backup/                  # Sauvegarde/restauration Moodle (moodle1, moodle2)
│   ├── classes/                 # Classes PHP (autoloading, namespace mod_glaaster\)
│   │   ├── analytics/indicator/ # Indicateurs d'analyse d'apprentissage
│   │   ├── event/               # Événements Moodle
│   │   ├── external/            # Web services externes (une classe par fonction)
│   │   ├── local/               # Classes internes
│   │   │   ├── ltiglaasterservice/  # Base des services LTI
│   │   │   ├── ltiopenid/       # LTI 1.3 OpenID Connect / enregistrement dynamique
│   │   │   └── types_helper.php
│   │   ├── output/              # Renderer + pages (Output API)
│   │   ├── plugininfo/          # Types de subplugins (ltiglaasterservice, ltiglaastersource)
│   │   ├── privacy/             # Conformité RGPD
│   │   ├── reportbuilder/       # Rapports (outils externes du cours)
│   │   ├── search/              # Intégration recherche globale
│   │   └── task/                # Tâches planifiées (clean_access_tokens)
│   ├── db/                      # Schéma, services, hooks, tâches, caches, capacités
│   ├── lang/                    # Fichiers de langue (en, fr)
│   ├── pix/                     # Icônes et images
│   ├── service/                 # Subplugins LTI (memberships, profile, toolproxy, toolsettings)
│   ├── source/                  # Emplacement des subplugins ltiglaastersource (readme)
│   ├── templates/               # Templates Mustache
│   ├── tests/                   # Tests PHPUnit et Behat
│   ├── LICENSE                  # Licence GPL v3
│   └── *.php                    # Points d'entrée PHP
├── .github/workflows/           # CI GitHub Actions (ci.yml, commitlint.yml, danger.yml)
├── .grunt/                      # Tâches et composants Grunt (Moodle)
├── docker/                      # Environnement local (docker-compose.yml, nginx.conf)
├── docs/                        # Documentation (ce dossier)
├── scripts/                     # buildzip.sh, bump-version.sh
├── Gruntfile.js                 # Configuration de build
├── package.json                 # Dépendances Node.js (Yarn 4.9.1)
├── composer.json                # Dépendances PHP (dev)
├── .releaserc.json              # Configuration semantic-release
├── Dangerfile / dangerfile.js   # Revue automatique des PR (Danger)
├── CLAUDE.md                    # Instructions pour Claude Code
└── README.md                    # Documentation utilisateur

Dossiers principaux​

/mod/glaaster/ - Racine du module​

Responsabilité : Point d'entrée principal du plugin Moodle.

Fichiers clés :

  • version.php - Version du plugin (release), dépendances Moodle
  • lib.php - API Moodle obligatoire (add_instance, update_instance, delete_instance)
  • locallib.php - Logique métier LTI (fonctions glaaster_* : launch, JWT, validation)
  • launch.php - Lancement : appelle glaaster_initiate_login() (LTI 1.3), transmet resource_id / file_name / file_path / redirect
  • view.php - Page d'activité (extraction params resource/folder, mode d'ouverture)
  • auth.php - Endpoint d'authentification OIDC LTI 1.3 (réponse id_token)
  • token.php - Génération de tokens OAuth2 (client_credentials) pour services LTI Advantage
  • services.php - Endpoint HTTP des services LTI (subplugins service/)
  • servicelib.php / OAuthBody.php - Utilitaires services + signature OAuth 1.0 du corps
  • contentitem.php / contentitem_return.php - Deep Linking (initiation / retour)
  • request_tool.php - Demande d'ajout d'un outil au cours
  • toolconfigure.php - Page admin en cartes : connexion (domaine, utilisateur/token API), activation des icônes contextuelles, mode d'ouverture
  • openid-configuration.php / openid-registration.php / startltiadvregistration.php - Enregistrement dynamique LTI 1.3
  • certs.php - Publication JWKS (clé publique de la plateforme)
  • mod_form.php - Formulaire de configuration de l'activité
  • settings.php - Réglages d'administration

/mod/glaaster/amd/ - JavaScript AMD​

Responsabilité : Modules JavaScript pour l'interface Moodle (format AMD requis par Moodle).

Workflow :

src/*.js → (Grunt : Babel + Rollup) → build/*.min.js

Modules clés :

  • before_footer.js - Boutons contextuels (formats standard et Tiles), setupContentObserver() et setupDeletionWatcher() (MutationObservers)
  • view.js - Lancement en nouvelle fenêtre / redimensionnement iframe
  • tool_configure_controller.js - Configuration d'outils LTI
  • external_registration.js - Enregistrement dynamique LTI 1.3
  • contentitem.js - Deep Linking
  • mod_form.js - Interactions formulaire d'activité

/mod/glaaster/assets/js/ - Scripts non-AMD​

  • iframe-loader.js - Loader de l'iframe LTI (mode intégré, chargé par view.php)

/mod/glaaster/backup/ - Sauvegarde / restauration​

  • moodle2/backup_glaaster_activity_task.class.php, backup_glaaster_stepslib.php - Sauvegarde
  • moodle2/restore_glaaster_activity_task.class.php, restore_glaaster_stepslib.php - Restauration
  • moodle1/lib.php - Conversion des sauvegardes Moodle 1.9

/mod/glaaster/classes/ - Classes PHP​

Responsabilité : Code PHP organisé selon le système d'autoloading Moodle.

classes/external.php​

external.php - Web services historiques (mod_glaaster_external)

Méthodes clés :

  • validate_instance() - Validation temps réel d'une instance Glaaster (AJAX, sans login)

classes/external/​

  • get_user_cohorts.php - Cohortes d'un utilisateur pour le Document Service (service glaaster_api, moodle/cohort:view requis)
  • get_tool_types_and_proxies.php, get_tool_types_and_proxies_count.php - Liste des outils
  • delete_course_tool_type.php, toggle_showinactivitychooser.php - Gestion des outils de cours

classes/helper.php​

helper.php - Utilitaires pour configuration d'outils LTI

classes/hook_callbacks.php​

hook_callbacks.php - Callbacks des hooks Moodle

Méthodes :

  • before_footer_html_generation() - Charge mod_glaaster/before_footer (js_call_amd)

classes/output/​

  • renderer.php + pages : tool_configure_page, course_tools_page, course_tools_page_header, external_registration_return_page, registration_upgrade_choice_page, repost_crosssite_page

classes/local/ltiopenid/​

Responsabilité : Implémentation LTI 1.3 / OpenID Connect

  • jwks_helper.php - Gestion des clés JWKS
  • registration_helper.php - Enregistrement dynamique LTI 1.3 (validation des URIs)
  • registration_exception.php - Erreurs d'enregistrement

classes/local/ltiglaasterservice/​

Responsabilité : Classes de base pour services LTI

  • service_base.php - Classe abstraite pour services
  • resource_base.php - Classe abstraite pour ressources REST
  • response.php - Gestion des réponses HTTP

/mod/glaaster/db/ - Définitions base de données​

Responsabilité : Schéma DB, web services, hooks, tâches planifiées.

Fichiers clés :

  • install.xml - Schéma de base de données (8 tables glaaster*)
  • install.php / upgrade.php - Installation et migrations
  • services.php - Web services (mod_glaaster_validate_instance, mod_glaaster_get_user_cohorts, …) et service pré-construit glaaster_api
  • hooks.php - Enregistrement du hook before_footer_html_generation
  • tasks.php - Tâches cron (clean_access_tokens)
  • access.php - Définition des capacités (permissions)
  • caches.php - Définition des caches
  • log.php - Événements de log
  • subplugins.json - Types de subplugins (ltiglaastersource, ltiglaasterservice)

/mod/glaaster/service/ - Subplugins LTI​

Responsabilité : Services LTI (subplugins ltiglaasterservice). Les services de notes (gradebookservices, basicoutcomes) ont été retirés.

SubpluginRôle
memberships/Names and Role Provisioning Service (NRPS) - contextmemberships, linkmemberships
profile/LTI Profile Service (LTI 2.0)
toolproxy/Tool Proxy Service (LTI 2.0)
toolsettings/Tool Settings Service - systemsettings, contextsettings, linksettings

Structure type :

memberships/
├── classes/local/
│   ├── service/memberships.php    # Service principal
│   └── resources/*.php            # Ressources REST
├── classes/privacy/provider.php   # Déclaration RGPD
└── version.php                    # Version du subplugin

/mod/glaaster/templates/ - Templates Mustache​

Responsabilité : Rendu HTML via l'Output API (depuis 5.0), p. ex. tool_configure.mustache, view_iframe.mustache, loader.mustache, contentitem.mustache, repost_crosssite.mustache, external_registration*.mustache, tool_proxy_card.mustache.

/mod/glaaster/lang/ - Fichiers de langue​

  • lang/en/glaaster.php - Anglais (langue principale)
  • lang/fr/glaaster.php - Français
  • lang/*/deprecated.txt - Chaînes dépréciées

/mod/glaaster/tests/ - Tests automatisés​

Organisation :

tests/
├── *_test.php             # Tests PHPUnit (lib, locallib, servicelib, externallib, …)
├── mod_glaaster_testcase.php  # Classe de base
├── external/              # Tests des web services (dont get_user_cohorts_test.php)
├── local/                 # Tests ltiopenid et types_helper
├── privacy/, task/        # Tests RGPD et tâche clean_access_tokens
├── behat/*.feature        # Scénarios Behat
├── fixtures/              # Données de test (tool_provider.php, cartouche IMS)
└── generator/             # lib.php + behat_mod_lti_generator.php

  • .releaserc.json - semantic-release (commit-analyzer, exec, git, github)

Documentation​

  • README.md - Documentation utilisateur (anglais)
  • CLAUDE.md - Instructions pour Claude Code
  • docs/ - Documentation technique (français) et notes de version

Scripts​

  • scripts/buildzip.sh - Génération du ZIP de plugin Moodle
  • scripts/bump-version.sh - Mise à jour de version.php (appelé par semantic-release)

Fichiers clés par fonctionnalité​

LTI 1.3 Launch​

  1. view.php - Extraction params (course_module_id, file_name, file_path, redirect)
  2. launch.php - Appel glaaster_initiate_login()
  3. locallib.php:glaaster_initiate_login() - Requête d'initiation OIDC
  4. auth.php - glaaster_get_launch_data() puis signature via glaaster_sign_jwt() (id_token)

Validation d'instance​

  1. amd/src/before_footer.js - setupDeletionWatcher() (MutationObserver)
  2. classes/external.php - validate_instance()
  3. locallib.php:glaaster_retrieve_instance_from_tooldomain() - Logique de validation backend
  4. db/services.php - Enregistrement mod_glaaster_validate_instance

Boutons contextuels​

  1. classes/hook_callbacks.php - Hook injection
  2. amd/src/before_footer.js - Détection fichiers et injection boutons (état désactivé, mode nouvel onglet)
  3. view.php - Réception des params de fichier

Configuration admin​

  1. toolconfigure.php - Cartes connexion / icônes / mode d'ouverture
  2. classes/output/tool_configure_page.php + templates/tool_configure.mustache - Rendu

Conventions de nommage​

PHP​

  • Fonctions globales : glaaster_* (préfixe obligatoire ; l'ancien préfixe lti_glaaster_* a été supprimé)
  • Classes : namespace mod_glaaster\ (snake_case, convention Moodle)
  • Méthodes : snake_case (convention Moodle)

JavaScript​

  • Fichiers AMD : snake_case (tool_configure_controller.js, before_footer.js)
  • Fonctions : camelCase
  • Constantes : UPPER_SNAKE_CASE

Base de données​

  • Tables : {glaaster}, {glaaster_types} (préfixe module)
  • Champs : minuscules sans séparateur (convention Moodle, p. ex. typeid, validuntil)
